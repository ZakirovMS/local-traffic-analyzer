# Frontend: Local Traffic Analyzer

Стек: **React + TypeScript + Vite**.

## Установить перед запуском

- **Node.js** (версия 20 или выше)
Скачать можно по ссылке: [nodejs.org](https://nodejs.org/).
Проверка версии: `node -v`.

- **npm**
Перейдите в папку frontend репозитория и один раз установите локальные инструменты: `npm install`

## Рекомендуемые расширения для VS Code

- **ESLint** — Подсвечивает ошибки JavaScript/TypeScript прямо в редакторе. Те же правила, что проверяет CI.

- **ES7+ React/Redux/React-Native snippets** — Ускоряет написание React-компонентов (попробуйте набрать rafce в пустом файле и нажать Tab).

- **Auto Rename Tag** — Автоматически переименовывает закрывающий HTML/JSX-тег при изменении открывающего.

- **Path Intellisense** — Автодополнение путей при импорте файлов.

## Запуск

1.  Запустите сервер разработки:
    ```bash
    npm run dev
    ```
2.  В терминале появится ссылка (обычно `http://localhost:5173/`). Откройте её в браузере.

**Важно:** Пока сервер запущен, терминал «занят». Если вы меняете код и сохраняете файл, страница в браузере обновится сама. Чтобы остановить сервер, нажмите в терминале `Ctrl + C`.

## Структура проекта

Корневые файлы и папки:
*   `index.html` — главная HTML-страница (точка входа). Именно сюда добавляются теги `<script>` или `<link>`, если нужно.
*   `public/` — статические файлы (например, `favicon.ico`, картинки), которые не обрабатываются сборщиком.
*   `vite.config.ts` — конфигурация сборщика (сюда надо добавить прокси для связи с Go-бэкендом).
*   `package.json` — список зависимостей и команд.

Исходный код лежит в `src/`:
*   `api/` — функции для HTTP-запросов к Go-бэкенду (настройка axios).
*   `assets/` — картинки, шрифты, иконки, которые импортируются в компоненты.
*   `components/` — переиспользуемые UI-элементы (кнопки, инпуты, таблицы).
*   `features/` — бизнес-логика конкретных фич (компоненты, хуки, логика).
*   `hooks/` — глобальные React-хуки (например, `useWindowSize`).
*   `pages/` — целые страницы (Dashboard, Settings, NotFound).
*   `store/` — глобальный стейт приложения.
*   `types/` — TypeScript-интерфейсы (описание данных, которые приходят с Go).
*   `utils/` — вспомогательные функции (форматирование дат, чисел).
*   `App.tsx` — корневой компонент (здесь настраивается роутинг).
*   `main.tsx` — точка входа React (рендерит `App.tsx` в `index.html`).
*   `index.css` — глобальные стили.

## Команды

*   `npm run dev` — запустить локальный сервер.
*   `npm run build` — собрать проект для продакшена (создаст папку `dist`).
*   `npm run lint` — проверить код на ошибки через ESLint.
*   `npm run preview` — посмотреть, как выглядит уже собранный билд.
